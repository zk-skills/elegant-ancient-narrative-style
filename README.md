# elegant-ancient-narrative-style

古雅叙事风格引擎：将现代文本转化为具有古雅气韵的现代表达，通过叙事视角、情绪节制、语言节奏和思想层次完成转换。

## 安装

将本仓库复制到 Agent 的 Skill 目录，例如：

```bash
git clone https://github.com/zk-skills/elegant-ancient-narrative-style.git
cp -r elegant-ancient-narrative-style ~/.codex/skills/elegant-ancient-narrative-style
```

也可放入项目级目录 `<项目>/.agents/skills/`。

## 入口

Agent 执行入口为 [SKILL.md](./SKILL.md)。
